# Prashant Sathawane React Portfolio

Interactive React + JavaScript portfolio built with Vite.

## Run

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown by Vite.

## Build

`npm run build`

## Edit

- `src/main.jsx` contains project details, skills and page content.
- `src/styles.css` contains the design and responsive styling.
